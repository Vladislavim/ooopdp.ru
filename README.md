# ПДП — сайт

Статический сайт ПДП: готовые HTML-страницы для хоста и исходники сборки в одном репозитории. Корневой `index.html` — главная страница сайта.

## Быстрый запуск

Из корня репозитория:

```powershell
py -m http.server 4173
```

Открыть: <http://127.0.0.1:4173/>

Сайт не требует Node.js или установки пакетов для обычного запуска: хост раздаёт файлы как обычный статический сайт.

## Структура

```text
index.html                 # готовая главная
pages/                     # готовые внутренние страницы
shared/                    # общая оболочка, стили, скролл и поведение
assets/                    # изображения, логотипы, документы и WebP-производные
media/                     # актуальные hero-видео и poster
fonts/                    # шрифты внутренних страниц
vendor/lenis/              # локальная библиотека плавного скролла
src/
  data/                    # данные сайта и карта оптимизированных ассетов
  blocks/                  # переиспользуемые блоки
  content/<page>/parts/    # фрагменты контента страниц
  pages/                   # манифесты страниц и порядок блоков
  build.mjs                # детерминированная сборка
```

## Как менять сайт

Редактируемый источник — каталог `src/`. Готовые HTML в корне и в `pages/` пересоздаются сборкой, поэтому ручные изменения в них не сохраняются.

- Текст, изображения и отдельные секции страницы — `src/content/<page>/parts/`.
- Порядок блоков — массив `order` в `src/pages/<page>.page.js`.
- Повторно используемые блоки — `src/blocks/<name>/`.
- Общие шапка, форма контактов и футер — `src/blocks/header/`, `src/blocks/contact-form/`, `src/blocks/footer/`.
- Общие данные, маршруты и карта WebP — `src/data/site-data.js` и `src/data/asset-variants.js`.
- Общие анимации и плавный скролл — `shared/` и корневые CSS/JS-файлы; новые эффекты добавлять только при необходимости интерфейса.

Чтобы перенести блок на другую страницу, меняется только её манифест и, если нужно, добавляется источник блока в `src/blocks/`. Не нужно копировать разметку вручную между готовыми HTML.

## Сборка

Из корня репозитория:

```powershell
node .\src\build.mjs --write
node .\src\build.mjs
```

Первая команда обновляет готовые страницы. Вторая запускает проверку без записи и должна завершиться сообщением `0 outputs differ`.

Сборщик записывает только в каталог сайта и защищён от обращения к резервной копии `PDP-backup-before-structure`.

## Медиа

Браузер использует производные из `assets/inner-optimized/`, а исходные тяжёлые мастера в рабочую публикацию не включены. Для главного видео оставлены оптимизированный поток `media/hero_background-perf-v2.mp4`, совместимый fallback `media/hero_background-v2.mp4` и poster.

При добавлении нового изображения:

1. положить мастер в исходники;
2. создать WebP-производную;
3. добавить соответствие в `src/data/asset-variants.js`;
4. пересобрать сайт и проверить отсутствие битых ссылок.

## Публикация на хост

В корне документа сайта должны находиться `index.html`, `pages/`, `shared/`, `assets/`, `media/`, `fonts/` и `vendor/`.

Получить текущую версию:

```powershell
git clone https://github.com/Vladislavim/ooopdp.ru.git
```

Обновить уже склонированную копию:

```powershell
git pull origin main
```

После изменения исходников сначала выполнить сборку и проверку, затем закоммитить готовые HTML вместе с исходниками.

## Контроль перед публикацией

- главная открывается из корня;
- внутренние страницы открываются из `pages/`;
- сборка сообщает `0 outputs differ`;
- в браузере нет 404 для локальных ассетов;
- на внутренних страницах подключены общая оболочка и плавный скролл;
- резервные копии, отчёты, скриншоты и локальные каталоги тестов не публикуются.
